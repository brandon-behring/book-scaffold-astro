## How to use this template

1. Delete this file (`src/content/chapters/week01-hello-world.mdx`).
2. Copy a skeleton from `examples/chapter-template-academic.mdx` or
   `examples/chapter-template-tools.mdx` to start your first chapter.
3. Edit the frontmatter to match your chapter's metadata.
4. Write.

<SkillBox title="The minimum-viable book workflow">
1. Pick a profile (`BOOK_PROFILE=academic` or `tools`).
2. Write one chapter in `src/content/chapters/`.
3. `npm run dev` and visit `localhost:4321`.
4. Iterate.
5. `npm run build` and deploy (recipe 05).
</SkillBox>

## What's already wired up

- **Tufte 2-column layout** with three-tier responsive widths
- **Left chapter-nav sidebar** (visible at ≥1024px; hidden on mobile)
- **Dark mode** (toggle top-right; respects `prefers-color-scheme`)
- **Pagefind full-text search** (`/search/`)
- **Paged.js PDF export** (`npm run pdf` → `dist-pdf/book.pdf`)
- **18 callout components** across two pedagogical families
- **KaTeX math** with 36 pre-defined macros (academic profile only)
- **BibTeX → CSL JSON pipeline** for academic citations
- **Pre-flight content validator** (`npm run validate`)
