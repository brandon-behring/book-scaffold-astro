# WorkedExample

The `<WorkedExample>` component (v4.1.0, [#57](https://github.com/brandon-behring/book-scaffold-astro/issues/57)) backs the Sweller/Cooper worked-example-effect pedagogy. Native `<details>`; collapsed by default unless `expanded` is set.

## Collapsed (default)

<WorkedExample id="agent-loop" title="One Claude session, end to end">
Setup: write a focused CLAUDE.md with explicit instructions. Run `claude` in the project root.

```
> Implement user authentication using JWT tokens.
```

Claude proposes a plan, executes it incrementally, runs tests after each change. The session's final commit summarizes what changed and why.

Key insight: the agent loop is a fixed protocol; the variance lives in the CLAUDE.md.
</WorkedExample>
